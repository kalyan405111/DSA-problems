# DSA Problems

A collection of Data Structures and Algorithms (DSA) problems solved from platforms like **LeetCode**, along with clear explanations, approach breakdowns, and time/space complexity analysis for each solution.

This repo is meant to be a personal practice log as well as a reference for anyone preparing for coding interviews or learning DSA concepts from scratch.

---

## 📌 About

- 🧠 Solutions to problems from LeetCode (and other platforms as added)
- 💻 Code written in Python (and other languages where noted)
- 📝 Each solution includes the approach, a walkthrough/trace, and complexity analysis
- 🎯 Goal: build strong problem-solving skills for technical interviews (Full Stack Developer / SWE roles)

---

## 🚀 How to Use

1. Clone the repo:
   ```bash
   git clone https://github.com/kalyan405111/DSA-problems.git
   cd DSA-problems
   ```
2. Navigate to the topic folder you're interested in.
3. Open any solution file — each one includes:
   - Problem summary
   - Approach/intuition
   - Code with comments
   - Time & space complexity
